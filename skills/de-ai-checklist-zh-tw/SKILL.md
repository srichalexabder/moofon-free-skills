## 這個 skill 幫你做什麼

30 秒檢查一份繁中文字，判斷 AI 味有多重、問題出在哪裡。不幫你改全文，只幫你找到要改的地方。搭配 humanizer-zh-tw-pro 使用效果最好。

## 30 秒速查清單

讀一遍全文，每中一項打一個勾：

**結構（3 項）**
- [ ] 開頭是時代感開場（「在當今……的時代」）
- [ ] 有「首先／其次／最後」或「第一／第二／第三」的整齊骨架
- [ ] 結尾是樣板收尾（「總而言之」「邁向成功」「更美好的未來」）

**詞彙（4 項）**
- [ ] 抽象名詞連發：挑戰、機遇、永續、賦能、轉型、格局
- [ ] 「透過……」「藉由……」「值得一提的是」出現兩次以上
- [ ] 「不僅……而且……更……」這類三段式排比
- [ ] 全文沒有具體數字、人名、場景

**語氣（3 項）**
- [ ] 每段長度差不多，像切好的吐司
- [ ] 沒有一句話是你平常會說出口的
- [ ] 讀完之後，你記不住任何一句話

**判讀**：0-2 項，還可以；3-5 項，AI 味明顯；6 項以上，重寫比修改快。

## 修正對照

| 問題 | 改法 |
|---|---|
| 時代感開場 | 刪掉，從事情本身開始 |
| 首先／其次／最後 | 換成「先……再……」，或直接分段不編號 |
| 樣板收尾 | 刪掉。用一句具體結論收尾，或不收尾 |
| 抽象名詞連發 | 每個抽象詞換成一件具體的事 |
| 透過／藉由 | 刪掉連接詞，直接講動作 |
| 三段式排比 | 留一段最強的，刪掉另外兩段 |
| 沒有具體細節 | 加一個數字、一個名字、一個場景 |
| 每段一樣長 | 長短交錯。重要的一句話可以自己成一段 |
| 不像人話 | 問自己：這句話我會跟朋友這樣講嗎？不會就重寫 |
| 讀完記不住 | 全文只留一句最想讓人記住的話，其他都是配角 |

## 朗讀測試法

檢查完清單，最後做一次朗讀測試：

1. 大聲讀全文一遍。
2. 讀到卡住的地方，畫線。那裡就是還沒改好的地方。
3. 讀完之後，問自己記得哪一句。記不得，就把最重要的一句話移到最前面。
4. 讀起來像人說話，就過關。讀起來像在背稿，就再改。

## 操作步驟

1. **速查**：用清單打勾，30 秒。
2. **定位**：勾最多的那一類（結構／詞彙／語氣），就是主要問題。
3. **修正**：按對照表逐項改，或交給 humanizer-zh-tw-pro 改。
4. **朗讀**：讀一遍，通順就停手。
