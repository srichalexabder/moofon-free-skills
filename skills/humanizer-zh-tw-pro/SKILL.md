## 這個 skill 幫你做什麼

把 AI 生成的繁中文字改成像人寫的。不是換同義詞，是換語氣、換節奏、換具體程度。改完之後，意思一樣，讀起來不一樣。

## 核心原則

1. **具體取代抽象**：不要寫「提升競爭力」，寫「先把最痛的那件事做順」。
2. **短句優先**：一句話超過 30 字，先拆成兩句。
3. **留口語節奏**：人說話會停頓、會轉折、會留白。逗號可以多，句號也可以多。
4. **刪掉樣板句**：凡是放進任何文章都通順的句子，都是樣板句，先刪。
5. **不改原意**：語氣可以改，數字、主張、結論不能改。
6. **一處只改一次**：不要反覆修飾，改完讀一遍，通順就停手。

## AI 味檢查清單

改之前，先對照這份清單把問題標出來：

- [ ] 開頭是「在當今快速變化的時代」或類似的時代感開場
- [ ] 出現「總而言之」「綜上所述」「首先／其次／最後」這種論文骨架
- [ ] 三個以上的排比句整齊排列（「不僅……而且……更……」）
- [ ] 抽象名詞連發：挑戰、機遇、永續、賦能、轉型、格局
- [ ] 「透過……」「藉由……」當每段的開頭
- [ ] 每段長度差不多，像切好的吐司
- [ ] 沒有具體數字、沒有具體人名、沒有具體場景
- [ ] 結尾是「邁向成功的關鍵」「迎接更美好的未來」這類收尾
- [ ] 全文沒有一句話是你平常會說出口的
- [ ] 讀完之後，你記不住任何一句話

中三項以上，這篇文章就是 AI 味重災區。

## 常見樣板句對照表

| 樣板句 | 改法 |
|---|---|
| 在當今快速變化的時代 | 直接刪掉，從事情本身開始講 |
| 企業面臨著前所未有的挑戰與機遇 | 說出具體挑戰：「卡在中間：不轉怕被淘汰，轉了又怕白花錢」 |
| 透過數位轉型，企業能夠有效提升競爭力 | 數位轉型不是喊口號，是先把最痛的那一件事做順 |
| 總而言之，擁抱變革是邁向成功的關鍵 | 刪掉。用一句具體結論收尾，或不收尾 |
| 首先，其次，最後 | 換成「先……再……」，或直接分段不編號 |
| 不僅如此，更重要的是 | 刪掉連接詞，直接講下一件事 |
| 值得一提的是 | 刪掉。值得提就直接提 |
| 在某種程度上 | 刪掉。說清楚是哪種程度，或不要修飾 |
| 實現永續發展的目標 | 說出要做什麼事，不要只說目標 |
| 讓我們一起迎接更美好的未來 | 刪掉。用行動呼籲收尾（例如：先試一個 skill） |

## 操作步驟

1. **讀全文，標出 AI 味**：用上面那份清單，一句一句標。
2. **逐段改寫**：每段只做三件事——刪樣板句、換具體說法、拆長句。
3. **朗讀檢查**：大聲讀一遍。讀到卡住的地方，就是還沒改好的地方。讀起來像人說話，就過關。

## 實測範例

### 範例 1：公司公告

**改前**
在當今快速變化的時代，企業面臨著前所未有的挑戰與機遇。透過數位轉型，企業能夠有效提升競爭力，並實現永續發展的目標。總而言之，擁抱變革是邁向成功的關鍵。

**改後**
現在變得很快，企業卡在中間：不轉怕被淘汰，轉了又怕白花錢。數位轉型不是喊口號，是先把最痛的那一件事做順，競爭力才跟得上。

**改了什麼**：刪掉時代感開場與收尾樣板句；「提升競爭力」換成具體動作；用冒號加短句做出停頓。

### 範例 2：產品介紹

**改前**
本產品採用先進的 AI 技術，透過深度學習演算法，為使用者提供前所未有的智慧體驗。首先，它能夠自動分析您的需求；其次，它可以即時給出最佳建議；最後，它會持續學習與優化。

**改後**
這個產品做一件事：你把需求丟進來，它馬上給你一個能用的建議。用久了會越給越準，因為它記得你上次選了什麼。

**改了什麼**：刪掉「先進」「前所未有」「智慧體驗」等空詞；「首先／其次／最後」換成一句話講完三件事。

### 範例 3：活動邀請

**改前**
誠摯邀請您參與本次分享會，與我們一同探討產業趨勢，交流實務經驗。相信透過本次活動，您將收穫滿滿，迎接更美好的未來。

**改後**
這場分享會不講大趨勢，只講三個真實案例：一個做成了，兩個搞砸了。來聽聽搞砸的那兩個，值回票價。

**改了什麼**：刪掉「誠摯邀請」「收穫滿滿」「更美好的未來」；用具體承諾（三個案例）取代空泛邀請。

## 不適用

- 法律文件、合約、正式公文：語氣不能亂改。
- 學術論文：有固定寫作規範，不要套用。
- 數字與事實陳述：改語氣，不改數據。
