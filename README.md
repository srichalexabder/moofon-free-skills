## 怎麼用

Claude Code、Codex、Cursor 都能用：

1. 把 `skills/` 裡你想用的資料夾，放到你的 skills 目錄。
2. 跟 AI 說「用 humanizer-zh-tw-pro 幫我改這篇文章」。
3. 改完對照 `examples/before-after-30.md` 看語氣對不對。

也可以直接把 SKILL.md 的內容貼給你的 AI 工具，當作改寫指令。
